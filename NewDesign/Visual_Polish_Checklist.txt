# 🎨 Visual Polish Checklist — Assets to Create

Everything below is currently **missing** from your game. Items are sorted by visual impact (highest first).

## 🔴 Priority 1: UI Screens (Biggest Visual Impact)

These are full-screen images the player stares at. They set the tone for your game.

### 1. Main Menu Background
- **What**: Full-screen cyberpunk city background for the main menu
- **Current state**: Uses `Resources/UI/MenuBackground.jpg` — a generic dark image
- **Specs**: `1920×1080` PNG or JPG
- **Where it goes**: `Assets/Resources/UI/MenuBackground.jpg` (overwrite existing)
- **Design tips**: Neon-lit cityscape, rain effects, glowing signs. Think Subway Surfers splash screen but cyberpunk

### 2. Game Logo / Title Art
- **What**: Stylized "ENDLESS RUNNER" or your custom game title
- **Current state**: Plain white text generated in code
- **Specs**: `800×200` PNG with **transparent background**
- **Where it goes**: `Assets/ActiveMotion3D/Art/UI/GameLogo.png` (new)
- **Design tips**: Neon glow, chrome/metallic text, cyberpunk font. Could include a silhouette of a runner

### 3. Game Over Splash
- **What**: Background image or overlay for the Game Over screen
- **Current state**: Plain semi-transparent dark rectangle
- **Specs**: `1920×1080` PNG (can be semi-transparent)
- **Where it goes**: `Assets/ActiveMotion3D/Art/UI/GameOverBg.png` (new)
- **Design tips**: Shattered glass effect, red neon flicker, "glitch" aesthetic
